# HMServices website

Static website for HMServices, presenting technical consulting services in water, rural infrastructure, agriculture, environment, GIS, remote sensing, data analysis, and AI-supported decision support.

## Contents

- `index.html` - Main HMServices website page.
- `styles.css` - Main website styling.
- `bagre-case-study.html` - Bagré surface-water monitoring case study.
- `bagre-case-study.css` - Styling for the Bagré case study page.
- `assets/` - Logos and image assets used by the pages.

## Case study

The Bagré case study demonstrates seasonal surface-water monitoring using Sentinel-2 imagery, MNDWI, and change detection maps. The page presents mapped water extent, seasonal comparison, and clear limits on what the analysis can and cannot prove without field verification.

## Viewing locally

Open `index.html` in a browser. The home page links to the Bagré case study through `bagre-case-study.html`.

## Publishing with GitHub Pages

After the files are committed to the `main` branch, open the repository settings on GitHub, go to Pages, and publish from the `main` branch. If the files are at the repository root, choose the root folder.
